# 구구성 수호대

> 계산이 빨라질수록 내 군대가 강해지는 **초등 연산 라인 디펜스**.
> 로그인 없이 브라우저에서 바로 플레이. 기록은 기기에만 저장되고 서버로 아무것도 보내지 않습니다.

- 대상: 초등 2~4학년 (수학 '수와 연산')
- 화면: 가로 고정. 데스크톱 / 태블릿 / 폰 가로 모두 지원(최소 900×310)
- 번들: **약 1.1MB**(JS 48KB + 그림 890KB + 소리 60KB) — 학교 와이파이·저사양 크롬북 고려

## 바로 실행

```bash
npm install
npm run dev       # http://localhost:5183
```

## 빌드 · 배포

```bash
npm run build     # dist/ 에 정적 파일 생성
npm run preview   # http://localhost:5184 에서 빌드 결과 확인
```

`dist/` 폴더를 정적 호스팅에 그대로 올리면 끝입니다(Netlify·Vercel·GitHub Pages·학교 서버 등).
서버 코드, 데이터베이스, 환경변수, API 키가 **하나도 없습니다.**

### 파일 하나로 배포

```bash
npm run build:single   # dist-single/gugu-guardians.html (약 920KB)
```

그림·소리·코드를 전부 data URI로 넣은 **단일 HTML**입니다. 외부 요청 0건이라
더블클릭으로 바로 열리고(`file://` 검증 완료), 파일 하나만 올릴 수 있는 곳
(아티팩트·이메일·USB·엄격한 CSP 호스팅)에도 그대로 들어갑니다.
배경만 1024px로 재인코딩합니다 — base64가 원본의 약 1.33배로 부풀기 때문입니다.

## 어떻게 학습이 일어나는가

**3층 구조**이고, 각 층의 역할이 다릅니다.

| 층 | 위치 | 목적 |
|---|---|---|
| **L1 유창성** | 전투 중 하단 문제 | 이미 아는 것을 **빠르게**. 정답이 자원(셈력)의 주 공급원 |
| **L2 정확성** | 클리어 직후 '봉인 해제' 5문항 | 새 개념·오개념 교정. **별점을 여기서 결정** |
| **L3 파지** | 세션 간 SRS(1→3→7→21일) | 오래 기억하기 |

핵심 규칙 3가지:

1. **전투 중에는 새 개념을 가르치지 않는다.** 전투를 보면서 새로운 걸 배울 수는 없습니다. L1은 자동화 전용.
2. **오답은 처벌하지 않는다.** 성 HP를 깎지 않고, 콤보만 끊기며 힌트를 줍니다. 두 번 틀리면 정답을 알려주고 넘어갑니다.
3. **별은 게임 실력이 아니라 학습이 준다.** 전투를 이겨도 봉인 해제 문항을 못 풀면 별 1개입니다.

문제는 전부 **절차적으로 생성**합니다(문제은행 파일 없음). 교재를 옮겨 적지 않으므로 저작권 문제가 없습니다.

## 밸런스는 추측이 아니라 실측입니다

`tools/balance-probe.mjs` 가 **난이도(11) × 정답률(6) × 시드(5) = 330판**을 실제로 굴려 게이트를 판정합니다.

| 게이트 | 뜻 |
|---|---|
| G1 | 잘하는 아이의 한 판이 75~91초인가 |
| **G2** | **정답률 60%인 아이도 필수 10판을 전부 깰 수 있는가** (하드월 금지 — 가장 중요) |
| G3 | 문제를 안 풀면 후반에 막히는가 (학습 유인) |
| G4 | 정답률이 높을수록 실제로 빨라지는가 (역전 금지) |
| G5 | 한 판에 20문항 이상 푸는가 |
| G7 | 도전(보스)은 잘하는 아이가 깰 수 있는가 |

이 프로브가 기획 단계에서 실제로 잡아낸 설계 파탄:

- 적은 지수(1.16ⁿ)·아군은 선형(1.06ⁿ)으로 짜서 **ST6부터 전 실력 구간 전멸**
- **무한 스폰**이 "느릴수록 적이 쌓이는" 죽음의 나선을 만들어 저성취 아동을 막고 있었음 → 총 물량 고정
- 아군 성장에 필요한 재화가 **획득 가능량의 40배**(23,818 vs 540) → 성장을 진도 연동 자동으로 변경
- **4지선다(무작위 25%)로 스테이지 6개가 그냥 통과** → 주 입력을 숫자패드로 확정

## 폴더

```
src/sim/     전투 시뮬레이션 (DOM 의존 0 — 테스트에서 그대로 돌린다)
src/edu/     문항 생성·채점·Elo 숙련도·SRS·학년 게이트·학습 통계 (DOM 의존 0)
src/render/  Canvas 전장 렌더러 · 에셋 로더 · CC0 효과음
src/ui/      화면(메뉴·지도·출전·전투·봉인해제·결과·도감·엉킴봉인·기록·설정)
src/save/    저장 스키마(화이트리스트 정규화) · localStorage
tools/       밸런스 프로브 · 에셋 파이프라인 · 시각 QA · 전체흐름 E2E
docs/        RESEARCH(조사·저작권) · GDD(기획) · PLAN(실행계획)
```

`src/sim`·`src/edu`는 브라우저 API를 쓰지 않습니다. 그래서 브라우저 없이 전 로직을 검증할 수 있습니다.

## 저작권 안전 설계

같은 장르(사이드뷰 라인 디펜스)는 2007년 *Age of War* 등으로 이미 널리 퍼진 형식입니다.
다만 **국내 판례상 "게임 규칙은 무조건 자유"는 틀린 단정**이라, 규칙 유사성에 기대지 않고 설계했습니다.

- 자원 파이프 자체를 **학습으로 치환**(다른 게임에 없는 구조)
- 아트를 **한국 민화·단청**으로 원천 분리, **고양이 캐릭터 전면 배제**
- 유닛·재화·적 명칭 전부 자체 창작
- 문항은 절차 생성(교재 복제 없음)
- 마케팅 문구에 경쟁작 이름을 쓰지 않음

상세와 남은 확인 항목: `docs/RESEARCH.md §3`
